# Builtin Auditors

AgentGuard includes built-in backend auditing capabilities for reviewing stored traces and agent behavior after runtime.

Currently documented built-in auditor:

- [Agent Security Audit](../security_audit.md): an administrator-facing audit workflow that reviews full agent snapshots across users, sessions, and traces, with deterministic rule mode, LLM mode, and hybrid mode.

Use built-in auditors when you want a ready-to-use audit workflow without writing custom backend code.
